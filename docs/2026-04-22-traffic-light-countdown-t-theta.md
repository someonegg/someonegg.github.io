## 2. 参数定义

- `T`：周期时长（秒），信号状态重复一轮所需时间。
- `θ`：相位零点（秒），可理解为“某一参考轮次起点”在系统时间轴上的位置。
- `φ(t)`：时刻 `t` 的当前相位，定义为：

```text
φ(t) = (t - θ) mod T
```

其中 `φ(t)` 位于 `[0, T)`。

---

## 3. T 的观测构造：起步事件与偏移直方图

`T` 无法从单条轨迹直接算出，它的计算对象是一个统计量：**多天叠加的起步偏移直方图**。构造流水线：

```text
多天轨迹 → 样本筛选 → 每日首车对齐得 Δt → 多天聚合为偏移直方图
```

从直方图挖出 `T` 的方法见第 4 节。

### 3.1 观测原子：起步事件

**起步 = 一条轨迹中“速度从持续为 0 回升”的转变时刻**，记为 `t_start`。样本车辆与起步事件一一对应：样本口径是“在灯前停车等待过的车”，每条样本轨迹恰好贡献一个起步时刻；绿灯期间不停车直接通过的车不进样本，对统计零贡献。

起步时刻不等于绿灯点亮时刻：

```text
队首车起步   ≈ 绿灯起点 + 约 1s（反应时间）
队内第 k 辆 ≈ 绿灯起点 + (k-1) × h    （h 为平均车头时距）
```

因此每一轮绿灯放行的是**一簇**起步事件：簇头贴着绿灯起点，簇内按 `h` 逐辆展开；绿灯期内排队清空后，新到达的车不再停车（退出样本），簇自然衰减。簇形态是后续直方图周期性的来源（排队溢出使簇头后移的问题见第 7 节）。

### 3.2 样本筛选（专利明确的三个条件）

1. **连通路段对**：只取“从红绿灯连通的第一路段进入第二路段”的轨迹，确认是径直通过该灯的车道组。
2. **停车时长 ≥ 预设长度**：短暂刹停（避让、走走停停）视为噪声丢弃。
3. **轨迹分类模型剔除非机动车**：外卖电动车等启停行为与机动车不同，会污染分布。

### 3.3 每日首车对齐

对每天的目标时段（如 09:00–09:30），找**该时段内第一辆“由停等状态启动”的车**（专利称起始样本车辆），其起步时刻即当天基准 `t0(d)`；其余每辆车贡献一个偏移：

$$
\Delta t_i(d) = t_{start,i}(d) - t_0(d)
$$

两个要点：

- **首车不必是“时段内第一轮红灯的首车”**。若 09:00:00 恰逢绿灯且无排队，则第一辆停等并启动的车（可能是 09:03 那轮的）就是首车。对齐只需锚定到某个绿灯起点，相对化目的即达成。
- **为什么必须按天对齐，而非把多天绝对时刻直接拼接**：不同天绿灯起点的钟表时刻是错开的（周一 09:00:08 亮绿、周二 09:00:37 才亮），直接拼接会让各天的峰互相错位抵消。相对化丢掉的是绝对相位（这正是 `θ` 要在第 5 节在线补回的原因），留下的是周期结构本身。

工程加固（非专利原文，专利只写“第一个启动的”）：首车可能异常（起步速度异常、轨迹置信度低、停车时长过短），可顺延取下一个起步样本，或取前 N 个起步时刻的众数作为 `t0(d)`，避免单条异常轨迹让当日所有偏移整体错位。

### 3.4 多天叠加成偏移直方图

将多天的 `Δt` 汇总为直方图：**横轴为偏移时长（秒），纵轴为对应的样本车数量**。各类样本的落点如下：

| 角色 | Δt 落点 |
|---|---|
| 当天首车 | 0 |
| 同轮队内第 k 辆 | ≈ (k-1) × h |
| 第 m 轮绿灯放行的车 | ≈ mT + (k-1) × h |

直方图因此呈等间距峰列，**簇间距 = T**：

```text
数量
 │ ▌              ▌              ▌              ▌
 │ ▌▌             ▌▌             ▌▌             ▌▌
 │ ▌▌▄            ▌▌▄            ▌▌▄            ▌▌▄
 │ ▌▌▄▂▁          ▌▌▄▂▁          ▌▌▄▂▁          ▌▌▄▂▁
 └─┴──────┴───────┴──────┴───────┴──────┴───────┴──→ Δt
   0      T      2T     3T      4T     5T      6T
   ├─ 绿灯期：排队释放，起步密集，先高后低 ─┤├─ 红灯期：≈0 ─┤
```

多天叠加的作用：样本量成倍扩大、随机噪声被平均；低流量路口单日峰太稀，叠加后才能凑出可检测的周期。专利明说此设计服务于“车流量相对不高**但有车辆经过**”的路口——流量低可以，为零不行。

**数值例子**：设真实 `T = 90s`、绿灯约 25s、时段 09:00–09:30：

| 来源 | 起步时刻 | 当天 t0 | Δt | 解读 |
|---|---|---|---|---|
| 周一首车 | 09:00:08 | 8s | 0 | 第 1 轮绿灯起点（含反应时间） |
| 周一 车 A | 09:00:14 | 8s | 6s | 同轮队内第 2 位 |
| 周一 车 B | 09:03:11 | 8s | 183s | ≈ 2×90+3，第 3 轮首车（第 2 轮红灯无车） |
| 周二首车 | 09:00:37 | 37s | 0 | 周二自己的基准 |
| 周二 车 C | 09:05:02 | 37s | 265s | ≈ 3×90−5，第 4 轮附近 |

各天减去本日 `t0` 后合并，直方图在 0–25、90–115、180–205… 区间出现起步密集段，间距 90s。第 4 节介绍周期提取方法。

## 4. T 的周期提取与失效边界

### 4.1 谱分析路线（专利点名 DFT）

把直方图当作一段时域信号：

1. 时段长 `L`（如 1800s），按 1s 分箱，得计数序列 `x[n]`（`n = 0..N-1`，`N = L`）；
2. 做离散傅里叶变换：

$$
X[k] = \sum_{n=0}^{N-1} x[n]\, e^{-2\pi i kn/N}
$$

3. 丢弃直流分量 `k = 0`（它只反映样本总量），取幅值最大的频点 $k^{*}$；
4. 该频点对应周期 `T = N / k*`（秒）。

**分辨率限制**：相邻频点对应的周期差约为 `T²/N`。`N = 1800`、真实 `T = 90`s 时 `k* = 20`，相邻频点给出约 94.7s / 85.7s，粒度约 ±4s。工程上以 DFT 峰为初值，再在邻域局部精化（峰位插值，或检验候选 `T` 下各簇的相位集中度）。

专利原文只写“利用已有的周期挖掘算法（比如离散傅里叶变换）找出唯一周期”，细化方法留白，上述分箱与精化是常规工程做法。

### 4.2 等价替代：模数命中评分（博文路线）

也可对起步波时间差做“倍数命中”评分：

$$
r_j = \min\left(d_j \bmod T,\; T - (d_j \bmod T)\right)
$$

$$
\mathrm{score}(T) = \frac{1}{M} \sum_{j=1}^{M} \mathbf{1}\left[ r_j \le \epsilon \right]
$$

其中 $d_j$ 为相邻起步波的时间差，$\epsilon$ 取 3s 容差；在常见周期范围 30–180s 内暴力搜索使 score(T) 最大的 T。本质是**鲁棒化的最大公约数**：所有 $d_j$ 都应是 `T` 的整数倍，容差吸收起步延迟误差。

### 4.3 时段聚合（专利明确）

同一路口一天内可有不同配时。将一天切成多个时段（专利示例按半小时），每时段独立挖一个 `T`，再横向聚合：

- 相邻时段 `T` 相差在秒级以内 → 判定为同一配时，平均合并；
- 相差较大 → 多周期灯（早晚高峰/平峰/夜间不同 `T`），保留为该路口一天的“周期分布信息”。

### 4.4 失效边界：缺轮、低流量与倍周期

**缺一轮不移峰。** 某轮红灯没车，那一轮绿灯就没有起步事件，直方图只是缺一个峰，峰位网格不变：DFT 的基频仍在；评分法里 `d_j = 2T` 时余数为 0 照样命中。所以“每轮有车”不是算法前提，真正的下限是两条：

1. **样本绝对量不足**：多天叠加后一个时段仍只有零星几辆车，直方图稀疏，“唯一周期”检测置信度低。对策即 5.5 的置信度门控降级（不显示秒数，只给“预计等待”或关闭读秒）。
2. **倍周期混淆（更隐蔽）**：若流量低到每隔一轮才有一辆车，所有观测间隔都是 `2T`，则 `T' = 2T` 能完美解释全部数据且更“简单”，任何周期检测都会输出 `2T`。这在数据内部无法区分，只能靠外部信息破局：常见周期先验（30–180s）、与流量稍大的相邻时段交叉验证、或拉长观测窗。同理，样本只落在 `3T` 网格上时会误判 `3T`。

## 5. θ 的工程算法（必要但非该专利核心公开）

> 下述为工程化实现框架，用于解释倒计时如何“在线读秒”。专利只覆盖离线挖掘 `T`（第 3、4 节），在线相位跟踪未公开。

仅有 `T` 还不能读秒：第 3 节的按天对齐**刻意丢掉了绝对相位**，且信号机会重新配时、被交警手控、自适应配时下相位持续漂移。因此 `θ` 不是离线算好的参数，而是**在线维护的状态**，链路四段：

```text
锚点提取 → 相位跟踪 → 读秒换算 → 信任管理
```

### 5.1 锚点提取

在线使用 3.1 节的起步检测器，将时间相近的起步事件聚成**起步波**，取簇首时刻为 `t_obs`。

`t_obs` ≠ 绿灯起点，偏差有三类：

1. 队首司机反应时间（约 1s）与 GPS 上报、链路延迟（数秒）——近似**固定偏置**；
2. 被观测车不在真正队首（队首车辆未被采到）——**队列项** ≈ `q × h`，`q` 为前方未被观测的车辆数；
3. 排队溢出——队尾车需等前几轮放完，见第 7 节，需单独建模。

据此校正：

$$
t_{anchor} = t_{obs} - \delta, \qquad \delta \approx \delta_0 + q \cdot h
$$

`δ₀` 为固定偏置（可离线标定），`q` 由被观测车 GPS 位置到停车线的距离估计。`t_anchor` 是“本轮绿灯起点”的观测值，仍有秒级噪声，但应无偏——残差交给 5.3 的递推平均。

与第 3 节的分工：算 `T` 只用簇间距，簇内偏移天然被吸收，不需要 `δ`；读秒要的是绝对相位，簇内偏移直接变成相位误差，`δ` 校正因此成为必需。

### 5.2 θ 的含义与初始估计

把绝对时间轴上的绿灯起点看成网格 $g^* + kT$，`θ` 就是**网格原点**——模 `T` 的等价类：相差整数个 `T` 的两个 `θ` 完全等价。于是维护一个数即可，且

```text
θ 准  ⟺  任意时刻相位 φ(t) = (t - θ) mod T 准
```

冷启动时以首个锚点初始化：

$$
\theta_0 = t_{anchor} \quad (\text{相当于 } K = 1)
$$

任意一轮绿灯起点都是合法原点，**不需要知道锚点是第几轮**。初始误差等于单次观测误差（秒级），后续通过反馈精化。

若无任何观测（刚上线、夜间无车），`θ` 不存在，只能等首锚——这是 5.5“样本稀疏降级”的根源。

### 5.3 θ 的反馈更新：鉴相、修正与收敛

此后每轮绿灯产生一个锚点，走三步。

**① 鉴相：观测偏离预测网格多少**

```text
r = (t_anchor − θ) mod T          # 折到 [0, T)
e = r      若 r ≤ T/2
  = r − T  若 r > T/2              # 折到 [−T/2, T/2)
```

模运算自动吸收“第几轮”，`e` 只剩带符号相位差。数例（`T = 120`，θ = 09:00:00）：

| 锚点 | t_anchor − θ | r | e | 解读 |
|---|---|---|---|---|
| 09:58:47 | 3527s | 47 | **+47** | 观测比预测网格晚 47s |
| 09:59:50 | 3590s | 110 | **−10** | 比最近网格点早 10s |

wrap 是反馈能工作的前提：不折叠的话，一个锚点会把 θ 拽到半小时外。

**② 修正：只修一部分**

$$
\theta \leftarrow \theta + K \cdot e
$$

`e > 0` 表示真实起点比预测靠后，将 θ 向后修正 `K × e`。单个锚点带有秒级噪声，`K = 1` 会将噪声直接传给读秒；取较小增益相当于低通滤波，对历史观测加权平均。

**③ 增益与门限**

- 固定 `K` 常取 0.1–0.3；自适应 `K`：起步波车多、速度一致、定位好 → 大 K，反之小 K。
- 大残差门限：`e` 绝对值超过 `T/4` 多为配时突变/手控而非噪声，小步递推要拖 N 轮才爬过去（期间读秒全错），应直接重置 `θ` 或转入重估。
- 微频差无需特殊处理：真实周期 119.7s 而使用 `T = 120` 时，`e` 每轮带 +0.3s 系统偏移，递推令 θ 自动滑移跟上——一阶环天然吸收频率微差。

**收敛动态**（误差视角）：设 θ 相对真值偏差为 `x`，本轮观测误差为 `ε`，更新式成为

$$
x \leftarrow (1-K)\,x + K\,\varepsilon
$$

即 **θ 的误差每轮向最新观测误差收缩 `K` 比例**，θ 收敛到 `ε` 的指数加权均值；观测无偏则收敛到真值邻域。数值走一遍（真值网格 = 36s + 120k，K = 0.25）：

| 轮次 | ε | 更新前 x | e = ε − x | 更新后 x |
|---|---|---|---|---|
| 首锚 | +1.5s | — | — | +1.50 |
| 2 | −0.4s | +1.50 | −1.90 | +1.03 |
| 3 | +0.6s | +1.03 | −0.43 | +0.92 |
| 4 | −0.7s | +0.92 | −1.62 | +0.51 |
| 5 | +0.2s | +0.51 | −0.31 | +0.44 |

初始 +1.5s 的误差约 4–5 轮压到 0.4s（几何衰减，每轮 ×(1−K)）。反过来这也是 `K` 的选择依据：想 10 轮内收敛取 K ≈ 0.2，要更强抑噪取 K ≈ 0.1、接受约 20 轮收敛。

**无观测期间** θ 冻结，相位靠 `φ(t) = (t − θ) mod T` 纯外推，误差随“距上次校正的时间”累积（`T` 有微偏差时尤甚）——可信度必须随时间衰减，见 5.5。

### 5.4 倒计时计算

有了 `T` 与 `θ`，即可得当前相位：

$$
\varphi(t_{now}) = (t_{now} - \theta) \bmod T
$$

其余输入的来源：绿灯窗口 `[g_s, g_e)` 由离线偏移直方图的簇宽度（绿灯时长）与空档（红灯时长）估计；排队数 `n` = 本车 GPS 到停车线距离 ÷ 单车占用长度；`h` 为平均车头时距（秒/辆）。

**符号约定**

- 绿灯窗口在周期内的相位区间：`[g_s, g_e)`（`0 ≤ g_s < g_e ≤ T`）
- 本车前方排队车辆数（含本车）：`n`
- 每轮绿灯最大放行量：`C = floor((g_e - g_s) / h)`

**等待轮数与总等待时间**

所需绿灯轮数：

```text
k = ceil(n / C)
```

根据当前相位分两种情况：

*情况一：当前在红灯（`φ ∉ [g_s, g_e)`）*

```text
d = (g_s - φ) mod T          # 到下一次绿灯起点的等待时间
W = d + (k - 1) × T          # 总等待时间
```

*情况二：当前在绿灯（`φ ∈ [g_s, g_e)`）*

```text
C_rem = floor((g_e - φ) / h)  # 本轮绿灯剩余放行量
```

- 若 `n ≤ C_rem`：本轮即可通过，`W ≈ (n - 1) × h`（按排队位置顺序估算）
- 若 `n > C_rem`：本轮放不完，令剩余未放行量 `n' = n - C_rem`，转为情况一：

```text
d' = T - (φ - g_s)            # 到下一轮绿灯起点的等待时间
W  = d' + (ceil(n' / C) - 1) × T
```

**数值例子**：`T = 120`，绿灯 `[20, 50)`（30s），`h = 2` → `C = 15`。

- 例 A（红灯中）：φ = 100，n = 33 → k = ceil(33/15) = 3；d = (20 − 100) mod 120 = 40；W = 40 + 2×120 = **280s**。核对：40s 后第 1 轮放车 1–15，再 120s 放 16–30，再 120s 放 31–33——本车第 33，落在第 3 轮。
- 例 B（绿灯中）：φ = 30（本轮绿灯已过 10s），剩余 20s → C_rem = 10。
  - n = 8 ≤ 10：本轮通过，W ≈ 7×2 = **14s**；
  - n = 23 > 10：n' = 13，d' = 120 − (30 − 20) = 110，W = 110 + (1 − 1)×120 = **110s**。

### 5.5 置信度与降级

三个触发条件各对应一种统计含义：

| 触发条件 | 在说什么 |
|---|---|
| 残差 `e` 绝对值连续偏大 | θ 跟不上观测：系统性偏差，或配时已变（缓慢递推在硬扛错误） |
| 残差方差突增 | 观测散开、不再对齐网格：信号本身不规律（手控/自适应配时） |
| 样本稀疏（夜间、低流量） | 无新观测，θ 开环外推，误差随流逝时间按周期微偏差累积 |

降级即按 θ 可信度分层输出：

1. 精确读秒（残差小且校正新鲜）；
2. 只显示“预计等待 N 轮”；
3. 关闭该路口读秒。

可信度同时取决于观测质量与校正时效：距上次校正越久，可信度越低。

## 6. 一个可落地的最小实现框架

### 6.1 离线任务（小时级）

输入：多天轨迹样本。
输出：`T_by_intersection_by_timeslot`。

步骤：
1. 样本清洗（停车阈值、轨迹分类）。
2. 计算每日 `t0(d)` 与 `Δt`。
3. 聚合偏移分布。
4. 周期检测得到 `T` 与置信度。
5. 写入配置中心/特征库。

### 6.2 在线任务（秒级）

输入：最新轨迹流与离线 `T`。
状态：每路口维护 `θ`、残差统计、置信度。
输出：倒计时秒数与等待轮数。

步骤：
1. 检测起步波事件得到 `t_obs`。
2. 估计 `δ`（可选）并得 `t_anchor`。
3. 递推更新 `θ`。
4. 计算 `φ(t_now)` 与倒计时。
5. 置信度不足则降级。

## 7. 关键风险与对策

- 自适应信号导致 `T` 非常数。
  - 对策：改为分段 `T` 或短窗重估，低置信度时关闭读秒。
- 排队溢出使“起步时刻”偏离真实变灯时刻。
  - 对策：引入 `δ` 修正与拥堵场景单独模型。
- 右转放行/特殊渠化干扰样本。
  - 对策：车道级筛选，剔除干扰轨迹。
