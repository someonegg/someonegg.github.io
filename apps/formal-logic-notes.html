FORMAL LOGIC 概念 · 推理 · 边界

形式逻辑笔记把推理的每一步说清楚。

一个结论听上去挺有道理，就一定能从前提推出来吗？
从“有效性”开始，弄清形式逻辑能替我们把住什么关，又有哪些事它管不了。

7 个章节交互式反例检查经典命题逻辑入门
01 / 从论证开始

结论对不对，和推理有没有效，是两回事

一段论证由前提和结论组成。演绎逻辑盯住的是这两者之间的关系：有没有可能所有前提都成立，结论却错了？如果找不出这种反例，这段推理就是有效的。

有效性只问一件事：假如这些前提都成立，结论是不是必然跟着成立？
VALIDITY

有效性

只要不存在“前提全对、结论却错”的情况，推理就有效。它只管推理的结构过不过关，不管前提在现实里是不是真的。

SOUNDNESS

健全性

推理本身有效，而且每条前提在事实上也都成立。要判断现实里的说法靠不靠谱，光看逻辑不够，还得核对事实。

例子

“所有鱼都会飞；金鱼是鱼；所以金鱼会飞。”
推理结构完全有效，但第一条前提与事实不符，所以这段论证不健全。

注：本页中的“如果……那么……”按经典命题逻辑的实质蕴涵来理解。日常说话里的“如果”还常带有因果、先后或承诺的意味，写进形式系统时需要取舍。

02 / 经典原则

先把概念说稳，推理才经得起检查

谈起形式逻辑，最常被提起的往往是同一律、矛盾律和排中律。与其把它们背成几句口号，不如看清它们各自在守什么边界，以及在具体的逻辑系统里怎么起作用。

A = A

同一律 对象自身同一，讨论时词义保持一致

一个对象就是它自己。放到日常论证里，更常见的要求是别在中途偷换词义——这两层意思有联系，但一个是对象同一，一个是避免歧义，值得分清。

前提里的“银行”指金融机构，到了结论却指河岸，前后说的早就不是一回事了。

¬(P ∧ ¬P)

矛盾律 非矛盾原则

在经典逻辑里，同一个命题和它的否定不能同时成立。前提是说的是同一件事——对象、时间、条件和词义都得对齐，才谈得上自相矛盾。

“上午门开着，晚上门关了”是在说状态的变化，并不是逻辑矛盾。

P ∨ ¬P

排中律 非此即彼的边界

在经典逻辑里，一个命题和它的否定，总有一个成立。但这并不意味着我们已经知道是哪一个，更不是说随便挑出两个选项，就涵盖了全部可能。

“支持这个方案”和“不支持这个方案”才是互为否定；“支持方案”和“不关心问题”之间，还夹着不少其他态度。

充足理由律：讲道理的要求，还是关于世界的哲学主张？

莱布尼兹等人认为，凡是存在或发生的事，背后都有它之所以如此的充足理由。这其实是一条很有争议的哲学原则，并不是现代逻辑系统普遍采用的推理规则。要求别人说话拿出根据，和相信“世上每件事都有终极解释”，是两码事。

物理世界里的随机现象，也不能简单拿来一举推翻所有版本的充足理由律——得先说清这里的“理由”指的是决定论原因、概率规律，还是其他形式的解释。延伸阅读 ↗

03 / 交互图解

检验一条推理，最直接的办法是找反例

把“下雨”记作 P，“地面湿”记作 Q。先固定第一条前提“如果 P，那么 Q”，再分别换上不同的第二条前提，看看结论还能不能稳稳推出来。

肯定前件

P → QP∴ Q

04 / 日常讨论

先找出推理里的缺口，再给谬误起名字

日常争论里的逻辑毛病五花八门，往往牵扯词义、证据、因果或跑题，很难一一硬塞进某条基础定律里。比起急着贴上“某某谬误”的标签，更有用的是直接指出：哪一步缺了前提，或者证据根本撑不起结论。

01偷换概念词义悄悄变了

“这款产品很轻，所以它的影响一定微不足道。”

前面的“轻”说的是重量，后面的“微不足道”说的是分量和影响。概念中途换了意思，推理就断了。

02虚假两难硬把选项压缩成两个

“你不支持这个方案，就是不关心团队。”

反对眼前的方案，完全可能是因为想改得更好，或者有别的备选。问题不在排中律，而在说话的人把两个并不穷尽的选项说成了全部可能。

03诉诸无知把“没证明”当成“已证明”

“没人能证明这个传言是假的，所以它一定是真的。”

拿不出反证，不代表正面说法就成立。当然，如果是经过可靠排查、本该查出迹象却一无所获，“没查到”本身也可以作为证据，这要结合具体场景判断。

04事后归因先后发生不等于因果

“换了桌面壁纸之后成绩提上去了，看来壁纸真管用。”

成绩变化还可能来自复习更扎实、试卷变简单，或者正常波动。要确认因果，得把这些替代解释和干扰因素逐一排开。

05循环论证拿结论来证明结论

“这个消息源很可靠，因为它说的一向都是真的；而它说的是真的，因为它一向可靠。”

兜了一圈，前提里其实藏着结论本身，并没有给出独立的依据。哪怕在形式上挑不出毛病，它也说服不了原本就不信结论的人。

06稻草人与滑坡歪曲靶子，或跳过中间步骤

“你建议少开点会，就是反对团队沟通。”

这是先帮对方立一个更容易挨打的靶子，再猛烈攻击。另一类常见手法是滑坡：从一个温和的改动一路推到极端后果，却省掉了中间每一步为什么必然发生。不过，如果每一步风险都有扎实证据支撑，连锁推演本身并不是谬误。

哥德尔不完备定理，并不是“逻辑没用”的免死金牌

只要一个形式理论自身不矛盾、公理能按规则机械列出，而且表达能力足够涵盖基本算术，里头就一定存在既证不出来、也推翻不了的命题。它划出的是特定形式理论的能力边界，绝不是在说“逻辑失效了”或者“什么观点都没法判断”。

06 / 方法与争议

谈变化与发展，不等于放弃推理的严谨

黑格尔的辩证法关心的是：概念如何在自身局限与内在张力中一步步向前推进。把它压缩成“正题—反题—合题”的三段公式，其实会漏掉它的核心做法；至于辩证法里的“矛盾”和形式逻辑里的矛盾是不是一回事，哲学界也一直存在不同解读。

形式逻辑关心

结论能不能从前提推出

先把语言、规则和前提定清楚。形式逻辑也不是只能看静止的世界——引入时间参数或时态逻辑，一样可以刻画变化。

辩证法关心

概念如何暴露局限并推进

“扬弃”同时带着否定与保留的意思。它是一条分析概念演变的哲学路径，但每一次推进照样得讲清理由，不能只靠口号带过。

这里只做入门对照，并非对两种传统的完整概括。Hegel’s Dialectics ↗

波普尔的追问：什么证据能让你改口？

波普尔看重可证伪性与批判检验，最警惕那种“无论发生什么都能圆回来”的理论。对经验科学来说，一个有信息量的判断，得说清楚它排除了哪些可能观察到的事实。当然，数学证明、哲学论证和经验科学的检验方式各不相同，不能混为一谈。

波普尔对历史主义和黑格尔的批评影响深远，但他对黑格尔的解读和历史归因本身也颇多争议，读的时候不妨两边对照着看。观点与批评 ↗

把讨论拉回可检查的层面
  1. 定义关键词在前后有没有悄悄换了意思？
  2. 条件谈论的对象、时间和适用范围一致吗？
  3. 依据前提和结论之间，靠哪条证据或推导连起来？
  4. 修正如果出现什么反例，我们会愿意修正自己的判断？
