# Anthropic

## What this entity is

- 大模型研究与产品公司；在当前 wiki 中主要与 Claude、模型内部状态、机制可解释性和安全相关特征研究关联。

## Claims in current wiki

- 来源 `sources/2026-04-14-harness-reasoning-shift-wechat` 引用其《Emotion Concepts and their Function in a Large Language Model》作为“内部状态可能驱动捷径行为”的机制线索。
- 来源 `sources/2024-05-21-anthropic-mapping-mind-language-model` 记录其使用 dictionary learning / `SAE` 从 Claude 3.0 Sonnet 中抽取数百万可解释特征，并通过特征干预验证部分特征对行为有因果影响。
- 来源 `sources/2025-03-27-anthropic-circuit-tracing` 记录其提出 `CLT + Attribution Graph` 方法，从特征识别推进到特定 prompt 上的计算路径追踪。
